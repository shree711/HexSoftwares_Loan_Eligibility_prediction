# Loan Eligibility Prediction

This project is a machine learning-based loan eligibility predictor using logistic regression and random forest classifiers. It analyzes applicant details and predicts whether a loan application is likely to be approved.

## Dataset
The dataset used in this project is `LoanApprovalPrediction.csv`, which includes the following columns:

- Gender
- Married
- Dependents
- Education
- Self_Employed
- ApplicantIncome
- CoapplicantIncome
- LoanAmount
- Loan_Amount_Term
- Credit_History
- Property_Area
- Loan_Status (Target)

##  Technologies Used

- Python 3.x
- pandas
- numpy
- scikit-learn
- matplotlib / seaborn (optional for visualization)

## Model

- Preprocessing: Handling missing values, label encoding, feature scaling
- Algorithms:
  - Logistic Regression
  - Random Forest Classifier
- Evaluation: Accuracy, Confusion Matrix, Classification Report
